# Guided project workspace

Copy the templates into your own folder; do not edit the teaching data.

- `data/teaching_fermentation.csv` — synthetic, balanced teaching data. Not thesis measurements.
- `templates/stage1_balance.py` — starter with TODOs.
- `templates/stage2_design.md` — experiment template.
- `templates/report.md` — final report skeleton.
- `RUBRIC.md` — scoring.

Run from the module root. Keep the report, model and commands together.
