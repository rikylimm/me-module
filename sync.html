Cloud sync

Moves the tracker’s progress between devices through either a secret gist or a private repository.

Where to store the state

GitHub token

Fine-grained token → Account permissions → Gists: Read and write (nothing else).

Gist

Create a fresh secret gist, or paste one you already made.

Private repository

Create a private repo (e.g. me-sync). The token needs Contents: Read and write on that repo only.

Sync

Close any other tracker tab first — a stale tab would overwrite the merged state. “Sync and open” then loads a fresh tracker with the merged progress.

Open the tracker without syncing →

Security. The token is stored in this browser for this site. Use a token that can do only what this page needs (gists, or Contents on one private repo). A private repo is genuinely private; a secret gist is unlisted, not encrypted — anyone with its URL can read it.

This page must be opened from the same site as the tracker (both at https://NAME.github.io/study-tracker/), because the two pages share the browser’s local storage. It does not work from a local file.
